# am-motors-storefront

Inventory-first dealership storefront for AM Motors (UAE).

Status: Phase 1 (Foundation). No data source is connected yet; the site shows a truthful
"inventory temporarily unavailable" state. Production deployment is not allowed yet.

```bash
npm ci
npm run dev      # http://localhost:3000
npm run verify   # lint → typecheck → test → build
```
